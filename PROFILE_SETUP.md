# Profile README Automation

## Active profile workflows

| Workflow | Output | Schedule |
|---|---|---|
| Generate Profile Analytics | assets/profile-analytics.svg | Daily |
| Generate LeetCode Stats | assets/leetcode.svg | Daily |
| Generate Contribution Snake | assets/github-snake.svg and assets/github-snake-dark.svg | Daily |

All active dashboard visuals are stored in the repository and displayed directly in the profile README. No analytics section is hidden in a dropdown.

## GitHub Analytics

The profile analytics SVG is generated by the repository's own GitHub Actions workflow using GitHub's public REST API.

It displays:
- Public non-fork repository count
- Stars across those public repositories
- Forks across those public repositories
- Public profile followers
- Primary programming languages represented by repository count

The card is a public repository snapshot, not an IDE coding-time tracker or a byte-level language usage chart. It refreshes daily and can also be run manually.

No third-party GitHub Metrics token is required.

## Contribution Snake

- Outputs: assets/github-snake.svg and assets/github-snake-dark.svg.
- Uses the repository's built-in GITHUB_TOKEN.
- Workflow: Generate Contribution Snake.
- The README switches the image based on visitor light/dark theme preference.

## Removed integrations

Third-party GitHub Readme Stats and activity-graph endpoints returned HTTP 503/402 errors. Their cards and updater were removed. The GitHub Metrics workflow was removed because its token configuration was not supported. No broken external analytics images are included.

WakaTime is not configured because no WakaTime account is in use.

## Run manually

Open the repository Actions tab and run:
1. Generate Profile Analytics
2. Generate LeetCode Stats
3. Generate Contribution Snake

## Privacy

The analytics generator reads public GitHub profile and repository metadata only. It does not publish private repository contents, issue contents, credentials, or employer data.
